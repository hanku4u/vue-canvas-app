# API contract

The contract between the Vue frontend and FastAPI. Once the backend exists, FastAPI's generated OpenAPI schema is the source of truth, and the frontend's TypeScript types are generated from it. This document is the agreed starting point.

## Conventions

- Base path `/api`. JSON bodies, `camelCase` fields (Pydantic `alias_generator=to_camel`).
- Identity from the `x-knox-id` header (set by the gateway). No other auth.
- IDs are UUIDs generated by the client for components and groups (so ops can reference new items before the server responds), and by the server for canvases.
- Timestamps are ISO 8601 UTC.
- Every response carries `x-request-id`.

### Errors

```json
{ "error": { "code": "VERSION_CONFLICT", "message": "Component was changed by k.lee", "requestId": "…", "details": {} } }
```

| HTTP | Codes |
| --- | --- |
| 400 | `INVALID_PARAMS`, `INVALID_OP`, `INVALID_CONFIG`, `RANGE_TOO_LARGE` |
| 401 | `UNAUTHENTICATED` |
| 403 | `FORBIDDEN`, `CONTAINS_UNEDITABLE`, `ADMIN_REQUIRED` |
| 404 | `NOT_FOUND` (also used when you lack view access) |
| 409 | `VERSION_CONFLICT` |
| 413 | `RESULT_TOO_LARGE` |
| 429 | `TOO_MANY_QUERIES` |
| 502 / 504 | `UPSTREAM_ERROR`, `UPSTREAM_BAD_RESPONSE` / `UPSTREAM_TIMEOUT` |

## Me and users

### `GET /api/me`

```json
{ "knoxId": "j.doe", "displayName": "Jane Doe", "isAdmin": true }
```

### `GET /api/users?search=jan&limit=20`

Known users (anyone who has used the app), for the share and ACL dialogs.

```json
{ "items": [{ "knoxId": "j.doe", "displayName": "Jane Doe" }] }
```

## Canvases

### `GET /api/canvases?scope=mine|shared&search=&limit=&cursor=`

```json
{
  "items": [{
    "id": "c0f…", "title": "ET-04 CD excursion", "description": "",
    "owner": { "knoxId": "j.doe", "displayName": "Jane Doe" },
    "role": "owner", "componentCount": 7, "version": 3, "updatedAt": "2026-11-07T14:02:00Z"
  }],
  "nextCursor": null
}
```

- `role` is `owner`, `editor`, `viewer`, or `admin` (access only through admin rights, with no ownership or share).
- `version` lets list views send `canvas.update` ops (rename) without loading the full canvas.
- `scope=all` is admin-only (`403 ADMIN_REQUIRED` otherwise).

### `POST /api/canvases`

Request `{ "title": "New canvas", "description": "" }` → `201` with the full canvas (as in GET).

### `GET /api/canvases/{id}`

```json
{
  "id": "c0f…", "title": "ET-04 CD excursion", "description": "",
  "owner": { "knoxId": "j.doe", "displayName": "Jane Doe" },
  "role": "editor",
  "canManageAccess": false,
  "version": 7, "revision": 142,
  "defaultFilters": { "time_range": { "relative": "last_7d" }, "tool_id": ["ET-04"] },
  "groups": [{
    "id": "g1…", "title": "Chamber A", "x": 100, "y": 80, "w": 1400, "h": 900,
    "zIndex": 0, "collapsed": false,
    "defaultFilters": { "chamber": ["A"] }, "version": 3
  }],
  "components": [{
    "id": "n1…", "type": "chart", "title": "SPC – CD_MEAN", "groupId": "g1…",
    "x": 20, "y": 60, "w": 640, "h": 360, "zIndex": 1,
    "config": { "dataset": "spc_points", "kind": "spc", "...": "..." },
    "configVersion": 1, "version": 5,
    "access": { "canEdit": true, "viewRestricted": false, "editRestricted": false },
    "updatedBy": "k.lee", "updatedAt": "2026-11-07T13:40:00Z"
  }]
}
```

Components the caller can't view are omitted.

### `POST /api/canvases/{id}/ops`

Apply a batch of edits atomically.

```json
{
  "ops": [
    { "op": "component.create", "component": { "id": "n9…", "type": "note", "groupId": null,
      "title": "Notes", "x": 0, "y": 0, "w": 320, "h": 200, "zIndex": 4,
      "config": { "markdown": "", "color": "yellow", "fontSize": "md" }, "configVersion": 1 } },
    { "op": "component.update", "id": "n1…", "version": 5, "set": { "x": 40, "y": 60 } },
    { "op": "component.delete", "id": "n3…", "version": 2 },
    { "op": "group.create", "group": { "id": "g2…", "title": "Litho", "x": 0, "y": 0, "w": 800, "h": 600 } },
    { "op": "group.update", "id": "g1…", "version": 3, "set": { "title": "Chamber A+B" } },
    { "op": "group.delete", "id": "g2…", "version": 1, "mode": "ungroup" },
    { "op": "canvas.update", "version": 7, "set": { "title": "ET-04 CD", "defaultFilters": { } } }
  ]
}
```

- `set` may contain only editable fields: `title, groupId, x, y, w, h, zIndex, config, configVersion` for components; `title, x, y, w, h, zIndex, collapsed, defaultFilters` for groups; `title, description, defaultFilters` for the canvas.
- `group.delete` has `mode`: `"ungroup"` (keep contents) or `"withContents"`.

Responses:

```json
// 200
{ "revision": 143, "versions": { "n1…": 6, "n9…": 1, "g1…": 4, "canvas": 8 } }

// 409
{ "error": { "code": "VERSION_CONFLICT", "details": {
  "conflicts": [{ "opIndex": 1, "id": "n1…", "current": { /* full component as in GET */ } }] } } }

// 403
{ "error": { "code": "FORBIDDEN", "details": { "deniedOps": [2] } } }
```

The batch is all-or-nothing.

### `DELETE /api/canvases/{id}`

Owner or admin. Soft delete → `204`.

### `POST /api/canvases/{id}/duplicate`

Request `{ "title": "Copy of …" }` → `201` with the new canvas. Copies only components visible to the caller, with no shares or restrictions.

## Sharing and restrictions

Owner or admin only.

### `GET /api/canvases/{id}/shares` · `PUT /api/canvases/{id}/shares`

```json
{ "shares": [{ "knoxId": "k.lee", "role": "editor" }, { "knoxId": "m.park", "role": "viewer" }] }
```

`PUT` replaces the full list.

### `GET /api/canvases/{id}/components/{cid}/access` · `PUT …`

```json
{
  "viewRestricted": true,
  "editRestricted": true,
  "acl": [{ "knoxId": "k.lee", "access": "edit" }, { "knoxId": "m.park", "access": "view" }]
}
```

`PUT` replaces flags and ACL and bumps the component `version`.

## Data

### `GET /api/datasets`

```json
{ "items": [{
  "id": "spc_points", "label": "SPC points", "category": "SPC", "description": "…",
  "params": [
    { "name": "tool", "type": "string[]", "required": true, "filter": "tool_id", "valuesFrom": null },
    { "name": "parameter", "type": "string", "required": true, "filter": null,
      "valuesFrom": { "dataset": "spc_parameters", "column": "parameter" } },
    { "name": "start", "type": "datetime", "required": true, "filter": "time_range.start" },
    { "name": "end", "type": "datetime", "required": true, "filter": "time_range.end" }
  ],
  "columns": [{ "name": "ts", "type": "datetime", "label": "Time" }, { "name": "value", "type": "float", "label": "Value" }],
  "tooltip": ["lot_id", "wafer_id"],
  "suits": ["chart", "table"]
}] }
```

### `GET /api/datasets/{id}/values/{param}?search=&limit=50`

Values for a parameter picker (via its `values_from`).

```json
{ "values": ["CD_MEAN", "CD_STD"], "truncated": false }
```

### `GET /api/filters`

Filter dimension vocabulary (from `filters.yaml`).

```json
{ "items": [{ "id": "lot_id", "label": "Lot", "type": "string_list", "hasValues": true, "default": null }] }
```

### `GET /api/filters/{id}/values?search=A12&limit=50`

```json
{ "values": ["A12345", "A12346"], "truncated": true }
```

### `POST /api/query`

```json
{
  "dataset": "spc_points",
  "params": { "tool": ["ET-04"], "parameter": "CD_MEAN",
              "start": "2026-10-31T00:00:00Z", "end": "2026-11-07T00:00:00Z" },
  "shape": { "kind": "timeseries", "x": "ts", "y": ["value", "ucl", "lcl"],
             "seriesBy": "chamber", "targetPoints": 1600 },
  "context": { "canvasId": "c0f…", "componentId": "n1…" },
  "cache": "default"
}
```

`cache`: `"default"` | `"refresh"`. `context` is for logging only.

Shape union:

```ts
type Shape =
  | { kind: 'raw'; columns?: string[]; limit: number }                          // limit ≤ 10000
  | { kind: 'timeseries'; x: string; y: string[]; seriesBy?: string;
      targetPoints: number; xRange?: [string, string] }
  | { kind: 'scatter'; x: string; y: string; colorBy?: string; maxPoints: number }
  | { kind: 'histogram'; column: string; bins?: number; groupBy?: string }
  | { kind: 'boxplot'; value: string; groupBy: string; maxOutliers?: number }
  | { kind: 'table'; columns?: string[]; offset: number; limit: number;
      sort?: { column: string; dir: 'asc' | 'desc' }[]; filters?: ColumnFilter[] }
  | { kind: 'wafer'; x: string; y: string; value: string; waferBy?: string;
      mode: 'single' | 'gallery' | 'stacked';
      aggregate: 'mean' | 'median' | 'std' | 'min' | 'max' | 'count';
      wafers?: string[] }                                                        // gallery paging
  | { kind: 'distinct'; column: string; search?: string; limit: number }
```

JSON response (columnar):

```json
{
  "columns": [{ "name": "ts", "type": "datetime" }, { "name": "value", "type": "float" },
              { "name": "chamber", "type": "string" }],
  "data": { "ts": ["2026-10-31T00:01:00Z"], "value": [41.2], "chamber": ["A"] },
  "meta": {
    "shape": "timeseries", "rowsUpstream": 1834221, "rowsReturned": 3200,
    "downsampled": true, "cacheHit": false, "asOf": "2026-11-07T14:05:12Z",
    "durationMs": 2140, "upstreamMs": 1890
  }
}
```

Shape-specific `meta` additions: `table` → `totalRows` (after column filters); `histogram` → `edges`; `wafer` → `xRange`, `yRange`, `valueRange`, `wafers` (all wafer IDs, for gallery paging).

Arrow response: when the request sends `Accept: application/vnd.apache.arrow.stream` and the result is large, the body is an Arrow IPC stream and `meta` is in the `x-query-meta` header (JSON).

## Admin

All admin endpoints require admin rights (`403 ADMIN_REQUIRED` otherwise).

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/admin/admins` | List admins (with `source: "db" | "config"`) |
| POST | `/api/admin/admins` | `{ "knoxId" }` grant admin |
| DELETE | `/api/admin/admins/{knoxId}` | Revoke admin |
| GET | `/api/admin/canvases?search=&owner=&deleted=` | All canvases with share and restriction counts |
| POST | `/api/admin/canvases/{id}/transfer` | `{ "newOwner": "k.lee", "keepPreviousAsEditor": true }` |
| POST | `/api/admin/canvases/{id}/restore` | Undo soft delete |
| GET | `/api/admin/users/{knoxId}/access` | Owned, shared, ACL entries, hidden-from components |
| POST | `/api/admin/users/{knoxId}/revoke-shares` | Remove all shares for a user |
| POST | `/api/admin/users/{knoxId}/transfer-all` | `{ "newOwner": "…" }` |
| GET | `/api/admin/usage/overview?from=&to=` | Tiles and time series |
| GET | `/api/admin/usage/datasets?from=&to=` | Per-dataset stats |
| GET | `/api/admin/usage/datasets/{id}?from=&to=` | Dataset detail |
| GET | `/api/admin/usage/slow?from=&to=&thresholdMs=` | Slow query list |
| GET | `/api/admin/usage/errors?from=&to=&code=` | Error list |
| GET | `/api/admin/health` | Data API, DB, cache, concurrency, app info |
| GET | `/api/admin/audit?from=&to=&actor=&action=` | Audit log |

## Later

- `GET /api/canvases/{id}/changes?sinceRevision=` for polling other users' edits.
- `POST /api/query/export` for an unshaped CSV export (streamed).
- `GET /api/admin/datasets` and `POST /api/admin/datasets/{id}/test` for the dataset test runner.
